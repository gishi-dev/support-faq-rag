# クリアエア AP-500 フィルターのお手入れと交換

お手入れの前に、必ず電源プラグをコンセントから抜いてください。

## プレフィルター（2週間に1回）

本体の背面パネルを外し、プレフィルターのほこりを掃除機で吸い取ってください。
汚れがひどい場合は水洗いし、日陰で完全に乾かしてから取り付けます。

## 集じんフィルター（交換目安：10年）

集じんフィルター「CF-50」は水洗いできません。表面のほこりを掃除機で軽く吸い取る程度にしてください。
交換の目安は10年です。これは1日に吸い込むたばこの本数を5本として計算した値で、使い方によって短くなることがあります。

## 脱臭フィルター（交換目安：10年）

脱臭フィルター「DF-50」は、においが取れにくくなってきたら、日光に半日ほど当てると脱臭力が回復します。
交換の目安は10年です。

## フィルター交換ランプ

運転時間が合計8,760時間（1日24時間運転で約1年）になると、フィルターのお手入れランプが点灯します。
お手入れの合図で、交換時期ではありません。お手入れ後に「リセット」ボタンを3秒長押しすると消えます。
