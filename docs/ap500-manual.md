# クリアエア AP-500 取扱説明書（空気清浄機）

クリアエア AP-500 は、集じんフィルターと脱臭フィルターを備えた空気清浄機です。適用床面積の目安は25畳です。

## 設置場所

本体の前後左右と上部は、壁や家具から30cm以上離してください。
カーテンの近くに置くと、吸い込み口がふさがれて性能が下がります。

## 運転モード

- 自動モード：ほこり・においセンサーの反応に合わせて、風量を自動で切り替えます。
- ターボモード：最大風量で30分間運転し、その後は自動モードに戻ります。
- おやすみモード：風量を弱にし、表示パネルの明かりを消します。
- 花粉モード：風量の強と弱を交互に切り替え、床付近の花粉を吸い込みやすくします。

## ランプの見かた

きれいセンサーのランプは、空気の汚れ具合に合わせて色が変わります。
緑はきれい、オレンジはやや汚れている、赤は汚れている状態です。

## 運転を始めたら赤ランプが消えない

設置した直後は、センサーが部屋の状態を学習するため、ランプが赤のまま続くことがあります。
24時間ほど運転を続けても変わらない場合は、センサーの窓（本体側面）のほこりを掃除機で吸い取ってください。
