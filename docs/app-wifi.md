# ソヨカ ホームアプリとWi-Fi接続

ソヨカ ホームは、ミストプラス HM-300 とクリアエア AP-500 をスマートフォンから操作できる無料アプリです。iOS 16以降、Android 11以降に対応しています。

## 本体をWi-Fiにつなぐ手順

1. ソヨカ ホームアプリを開き、「機器を追加」をタップします。
2. 本体の「Wi-Fi」ボタンを5秒長押しします。Wi-Fiランプが点滅したら、接続待ちの状態です。
3. アプリの画面に従って、ご家庭のWi-Fiのネットワーク名とパスワードを入力します。
4. Wi-Fiランプが点灯に変わったら、接続は完了です。

## つながらないとき

本体が対応しているのは、2.4GHz帯のWi-Fiだけです。5GHz帯のネットワークには接続できません。
ネットワーク名の末尾が「-G」や「-2G」のものが、2.4GHz帯であることが多いです。
ルーターと本体の距離が離れすぎている場合は、近づけてからお試しください。

## アプリでできること

- 電源のオン・オフ、運転モードの切り替え
- 入タイマー・切タイマーの設定
- 室内の湿度と空気の汚れ具合の確認（過去30日分のグラフ）
- フィルター交換時期のお知らせ

## 音声アシスタントとの連携

現在、音声アシスタントとの連携には対応していません。対応予定は未定です。

## 機器の登録を解除したい

アプリの「機器の設定」から「登録を解除」を選んでください。
本体を譲渡・処分する場合は、あわせて本体の「Wi-Fi」ボタンを10秒長押しして、Wi-Fi設定を初期化してください。
