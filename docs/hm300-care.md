# ミストプラス HM-300 お手入れ

お手入れの前に、必ず電源プラグをコンセントから抜いてください。ヒーター式で運転した直後は内部が熱くなっているため、30分ほど待ってから作業してください。

## 毎日のお手入れ

給水タンクの水は毎日入れ替えてください。残った水を継ぎ足して使うと、においや雑菌の原因になります。
タンクの内側は、水を入れて軽く振り洗いしてください。

## 2週間に1回のお手入れ（トレー・加湿フィルター）

1. 本体からトレーを引き出し、加湿フィルターを取り外します。
2. トレーは水洗いし、ぬめりはやわらかいスポンジで落とします。
3. 加湿フィルターは、ぬるま湯で押し洗いします。こすったり、もんだりしないでください。

## 1か月に1回のお手入れ（クエン酸洗浄）

加湿フィルターに白い水あかが付いたら、クエン酸で洗浄します。
ぬるま湯3Lにクエン酸大さじ2杯を溶かし、加湿フィルターを2時間つけ置きしてから、水でよくすすいでください。
塩素系・酸性の洗剤を混ぜて使わないでください。有毒なガスが発生するおそれがあります。

## 加湿フィルターの交換時期

加湿フィルターの交換目安は、1シーズン（約6か月）です。
お手入れをしても水あかが取れない場合や、においが気になる場合は、早めに交換してください。
交換用フィルターの型番は「HF-30」です。購入方法は「消耗品と部品の購入」をご覧ください。

## シーズンオフの保管

保管する前に、トレー・加湿フィルター・給水タンクを洗って、2〜3日しっかり乾かしてください。
湿ったまま保管すると、カビの原因になります。購入時の箱に入れ、湿気の少ない場所で保管してください。
