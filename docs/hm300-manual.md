# ミストプラス HM-300 取扱説明書（加湿器）

ミストプラス HM-300 は、気化式とヒーター式を組み合わせたハイブリッド式の加湿器です。適用床面積の目安は、木造和室で8畳、プレハブ洋室で14畳です。

## 設置場所

壁や家具から30cm以上離し、平らで安定した床に置いてください。
エアコンの吹き出し口の真下や、直射日光の当たる場所は避けてください。
本体を傾けたまま運転すると、水漏れの原因になります。

## 給水のしかた

1. 本体上部の給水タンクを持ち上げて取り外します。
2. タンクのキャップを開け、水道水を満水ライン（4.0L）まで入れます。
3. キャップをしっかり閉め、本体に戻します。

水道水以外（井戸水、浄水器の水、アルカリイオン水、ミネラルウォーター）は使わないでください。雑菌が繁殖しやすくなったり、フィルターに水あかが付きやすくなったりします。
アロマオイルは本体の故障の原因になるため、給水タンクには入れないでください。別売りの「アロマトレイ AT-1」を使うと、アロマを楽しめます。

## 運転モード

- 自動モード：室温に合わせて、湿度が50〜60%になるように運転します。
- のどケアモード：湿度65%を目安に運転します。就寝時のご利用に向いています。
- 静音モード：運転音を約25dBに抑えます。加湿量は少なくなります。
- 衣類ケアモード：部屋干しの洗濯物に向けて、送風を強めます。

## タイマー

切タイマーは2時間・4時間・8時間から選べます。
入タイマーは、ギシ ホームアプリから時刻を指定して設定します。本体のボタンでは設定できません。

## チャイルドロック

「モード」ボタンを3秒長押しすると、チャイルドロックがかかります。もう一度3秒長押しすると解除されます。
チャイルドロック中は、電源ボタン以外の操作ができません。
