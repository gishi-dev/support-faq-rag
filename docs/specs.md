# 仕様一覧

## ミストプラス HM-300（加湿器）

- 加湿方式：ハイブリッド式（気化式＋ヒーター式）
- 適用床面積：木造和室8畳、プレハブ洋室14畳
- 最大加湿量：500mL/h
- タンク容量：4.0L
- 連続加湿時間：約8時間（最大加湿時）
- 運転音：約25dB（静音モード）〜38dB
- 消費電力：最大280W（ヒーター使用時）、静音モード時10W
- 本体サイズ：幅360×奥行190×高さ380mm
- 質量：約5.2kg（タンクが空の状態）
- Wi-Fi：2.4GHz帯に対応

## クリアエア AP-500（空気清浄機）

- 適用床面積：25畳
- フィルター：プレフィルター、集じんフィルター（CF-50）、脱臭フィルター（DF-50）
- 運転音：約19dB（おやすみモード）〜52dB（ターボモード）
- 消費電力：3W（おやすみモード）〜48W（ターボモード）
- 本体サイズ：幅400×奥行230×高さ600mm
- 質量：約7.8kg
- Wi-Fi：2.4GHz帯に対応
