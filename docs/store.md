# 公式ストア：注文・配送・返品

## お支払い方法

クレジットカード、コンビニ払い、銀行振込、後払いに対応しています。
コンビニ払いと銀行振込は、ご注文から7日以内にお支払いがない場合、自動でキャンセルになります。

## 配送

ご注文から3営業日以内に発送します。お届け日の指定は、発送予定日の翌々日以降から選べます。
送料は全国一律550円（税込）です。5,000円（税込）以上のご注文は送料無料です。
沖縄・離島への配送は、通常より2〜3日多くかかります。

## 返品・交換

未開封の商品に限り、商品到着から8日以内であれば返品できます。返品の送料はお客様のご負担です。
開封後の返品は、初期不良の場合のみ承ります。
初期不良の場合は、商品到着から30日以内にサポート窓口へご連絡ください。新品と交換し、送料は当社が負担します。

## 領収書

領収書は、会員ページの購入履歴からPDFでダウンロードできます。宛名は自由に入力できます。
