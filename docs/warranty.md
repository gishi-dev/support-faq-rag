# 保証規定

## 保証期間

本体の保証期間は、お買い上げ日から1年間です。
公式ストアで購入し、会員登録をされた方は、保証期間が3年間に延長されます。
加湿フィルター・集じんフィルター・脱臭フィルターなどの消耗品は、保証の対象外です。

## 保証を受けるために必要なもの

保証書、またはお買い上げ日と販売店名がわかるレシート・納品書が必要です。
公式ストアでご購入の場合は、会員ページの購入履歴が保証書の代わりになります。

## 保証期間内でも有料になる場合

次の場合は、保証期間内でも有料修理になります。

- 取扱説明書に従わない使い方による故障（水道水以外の水の使用、アロマオイルの投入など）
- 落下・衝撃による破損
- 火災・地震・水害などの天災による故障
- 業務用など、一般家庭以外での使用による故障
- お客様ご自身による分解・改造

## 保証期間が過ぎた後の修理

保証期間が過ぎた後も、有料で修理を承ります。
修理用の部品は、製造終了後6年間保有しています。
